# Maths Learning Hub | 數學學習資源中心

A bilingual (Traditional Chinese / English) learning resource portal for HKDSE Mathematics students, integrating interactive tools for Core Mathematics and Module 2 (M2).

**Live site:** https://kingtmc314.github.io/maths-hub/

---

## Tools Included

### 數學（必修）Mathematics (Core)
| Tool | Description | Link |
|------|-------------|------|
| 3D 立體三角 | 3D solid geometry calculator with sine/cosine rule step-by-step solutions, PDF export, PWA support | [solid-geometry-calculator](https://kingtmc314.github.io/solid-geometry-calculator/) |

### 數學（模組二）Mathematics (Module 2)
| Tool | Description | Link |
|------|-------------|------|
| Linear Algebra Lab | Matrix operations, eigenvalues, diagonalisation, Aⁿ, 2D/3D visualisation | [linear-algebra-lab](https://kingtmc314.github.io/linear-algebra-lab/) |
| Series and Induction Calculator | Closed-form derivation, induction proofs, formula reference | [series-calculator-students](https://kingtmc314.github.io/series-calculator-students/) |
| Curve Sketching and Differentiation | f'(x)/f''(x) analysis, critical points, asymptotes, tangent lines | [curve-analyzer](https://kingtmc314.github.io/curve-analyzer/) |
| Integration: Area and Volume | Area/volume calculations, step-by-step solutions, preset questions | [integcalc-lab](https://kingtmc314.github.io/integcalc-lab/) |

---

## Tech Stack
- Pure HTML / CSS / JavaScript (no build step required)
- Hosted on GitHub Pages
- Bilingual toggle (ZH ↔ EN) with localStorage persistence
- Dark Academic design theme

## Deployment
This site is deployed via GitHub Pages from the `main` branch (`/` root).

To update: push changes to `main` and GitHub Pages will auto-deploy.
